drive-pull

Tarik file dari link Drive, tanpa muter-muter halaman konfirmasi.

Tempel link share Google Drive. Sistem pecah filenya jadi beberapa bagian dan menariknya sekaligus dari sisi server, baru dikirim ke kamu sebagai satu file utuh.

Sebelum mulai

  1. Buka sharing setting file di Drive, atur ke "Anyone with the link" sebagai Viewer.
  2. Salin link share-nya, tempel di kolom atas.
  3. File di bawah 5 MB langsung ditarik satu koneksi. Di atas itu, sistem otomatis pakai beberapa koneksi paralel biar lebih cepat.
Proyek portofolio — dibangun dengan PHP + Drive API v3.
